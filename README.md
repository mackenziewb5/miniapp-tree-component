# 多选功能树组件（Multi-Select Tree Component）

## 简介

这是一个支持多选功能的树形组件，适用于需要层级结构数据展示和选择的场景，例如分类选择、权限配置等。组件支持节点展开/收起、勾选状态管理，并能够根据初始值初始化选中状态。

## 功能特性

- 支持多选模式，勾选状态联动（父节点和子节点状态自动更新）。
- 支持 `未选中`、`选中` 和 `部分选中` 三种状态。
- 支持根据初始值初始化选中状态，适用于回显展示数据的情况。
- 支持节点展开和收起，优化用户体验。
- 三角标和勾选框使用 css 实现，无需引入额外图片资源。
